# Security

Report vulnerabilities privately rather than in a public issue.

Use GitHub’s private vulnerability reporting for this repository:

https://github.com/AOJ222/BlackAndWhite-macOS/security/advisories/new

Include the affected version, macOS version, what happened, and the smallest set of
steps or sample files needed to reproduce it. Do not include game files, disc images,
or personal saved games.

## Supported versions

Security fixes are aimed at the latest published release and the current `main`
branch. Older pre-release builds may not be updated.

Copyright concerns are not security reports; see `NOTICE.md` for the rights-holder
route.
