# macOS app

This folder builds the two macOS apps:

- **Black & White**: starts the game. On its first run it asks for the player’s own
  copy of the game, imports the files it needs, and checks them against
  `game-manifest.json`.
- **Black & White Settings**: changes screen mode, resolution, render scale, frame-rate
  limit, and sound without editing a settings file by hand.

The apps contain no game content. On first run, the player adds their own copy of
Black & White — the PC disc as an `.iso` disc image, a folder that is a copy of the
disc, or the folder the game is installed in. Any version works: the original disc,
a patched copy, or another language edition; the program files are generated by the
app during set-up.

## Building

A full build also needs the separate `bw-native` and `swarc` source trees. Those trees
are not included in this repository yet.

```sh
python3 native/app/build-app.py --release --out <folder>
python3 native/app/build-app.py --install
```

Use `--release` for a copy intended for another Mac. It does not bake the build Mac’s
game or disc folders into the app, so the first start always begins with disc set-up.

`build-app.py` compiles the first-start program in `frontdoor/`, packages the launcher
and game importer, bundles `bw_native` and its libraries, and builds the Settings app.
The bundle is signed ad hoc and is not notarised.

## Files and settings

The app keeps its files under:

- Game data: `~/Library/Application Support/Black & White/`
- Settings: `~/Library/Application Support/Black & White/settings.conf`
- Logs: `~/Library/Logs/Black & White/`

Profiles and saved games are stored below the game-data folder. Deleting the whole
`Black & White` support folder removes the imported game and its local data, so do that
only if you intend to set everything up again.

## Command-line tools

The in-app importer is the normal route. The same work is available from Terminal for
development:

```sh
python3 native/app/import-game.py --iso <disc-image>
python3 native/app/import-game.py --check "<folder>/Game"
```

`import-game.py` needs `unshield` available on the Mac. It does not install it.

## Tests

```sh
native/app/tests/frontdoor.sh
native/app/tests/picture-settings.sh
native/app/tests/settings-app.sh
python3 native/app/tests/icon.py
```

The front-door test can also run a full disc import when `BW_TEST_ISO` points to a
supported disc image.

## Icon

The release icon can be drawn from private logo artwork when that artwork is present
locally. It is not part of this repository. Without it, `build-app.py` draws the plain
fallback icon.

## Current limitations

- Apple silicon and macOS 27 are required for the current build.
- The app is not notarised.
- LAN multiplayer does not work.
