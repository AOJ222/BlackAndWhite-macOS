# Black & White for Mac

A native macOS port of **Black & White** (2001, Lionhead Studios) for Apple silicon.

The port contains **no game content**. On first start it asks for **your own copy of
Black & White**, reads the game from it, checks every file, and sets itself up. After
that it starts at once and your copy is not needed again. If you do not own the game,
this download cannot do anything for you.

## Download and play

The latest prebuilt release is on the GitHub Releases page.

1. Download the release zip and unzip it.
2. Move `Black & White.app` into Applications (`Black & White Settings.app` too if you want it).
3. Open it. It is not notarised, so on first launch macOS may refuse: System Settings →
   Privacy & Security → **Open Anyway** → **Open**.
4. Add your copy of the game: an `.iso` image of the disc, a folder that is a copy of
   the disc, or the folder the game is already installed in.
   Set-up takes under a minute and about 3 GB.
5. Play. Later starts go straight to the game.

**Requirements:** Apple silicon (M1 or later), macOS 27 for this build, your own copy
of the game.

**What you need:** your own copy of Black & White, in any version — the original PC
disc as sold, a patched copy (1.10/1.20, the Fan Patch), or another language edition.

## How it works

The original game's x86 code is statically recompiled to native Apple silicon code
(`bw_native`, built with the SwARc runtime) and runs against replacements for its Windows,
DirectDraw/Direct3D 7, DirectInput and Bink layers written for macOS (SDL and Metal). At
run time the only game files it reads are the ones it imported from your copy into
`~/Library/Application Support/Black & White`. The program files are generated by the
app during set-up, which is why every version of the game works the same way.

## Building from source

```
python3 native/app/build-app.py --release --out <folder>
```

This builds the apps from a `bw_native` build (the `bw-native` and `swarc` trees) and
bundles everything the first start needs, including the disc importer. Nothing from the
building Mac is baked into a `--release` build. This repository currently contains the
app and importer layer; the separate `bw-native` and `swarc` source trees are also
required for a full build and are not included here yet. See `native/app/README.md`
for the full picture: the launcher, the settings app, the manifest the game is
checked against, and the tests (`native/app/tests/`).

## Status

- Single-player is playable; Lands 1–5 run, and key moments are covered by turn-by-turn
  parity checks against the original game. The game is also checked by hand during
  development. A full start-to-finish campaign run is the current testing focus.
- Sound and the opening movies work; networking (LAN multiplayer) does not.
- The Settings app and the game's own Options screen change picture size and frame rate.
- Known limits are listed in `native/app/README.md` and `native/NOT-ORIGINAL.md`.
