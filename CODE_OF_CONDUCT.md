# Code of conduct

Be welcoming, patient, and respectful. Assume good faith, explain disagreements
plainly, and keep discussion focused on the work.

Harassment, discrimination, threats, personal attacks, and repeated disruption are
not acceptable in issues, pull requests, or project discussions. Maintainers may
edit or remove content, close discussions, or restrict participation where needed
to keep the project usable for everyone.

If you need to report conduct privately, contact a maintainer through GitHub and
ask for a private route. Reports will be handled as discreetly as the circumstances
allow.
